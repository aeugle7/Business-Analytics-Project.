# Employee Salary Benchmarking Using Excel and Power BI

## Project Overview
This project analyzes software industry salary data to understand compensation trends across job roles, employment types, and geographical locations.

The project uses Microsoft Excel and Microsoft Power BI to transform raw salary survey data into meaningful business insights.

## Objectives
- Clean and preprocess raw salary data.
- Perform exploratory data analysis (EDA).
- Calculate descriptive statistical measures.
- Develop DAX measures in Power BI.
- Build an interactive salary benchmarking dashboard.
- Identify salary trends across job roles and locations.

## Tools & Technologies
- Microsoft Excel
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

## Dataset
Source: Kaggle – Software Industry Salary Dataset (2022)

- Original dataset: Salary_Dataset_with_Extra_Features.csv
- Cleaned dataset: Salary_Dataset_Cleaned.csv
- Records after preprocessing: 21,615

## Data Preprocessing
- Handled missing and invalid values.
- Standardized job roles and employment status.
- Converted salary values into numeric formats.
- Prepared the cleaned dataset for analysis.

## Exploratory Data Analysis
- Mean, median and mode calculations.
- Standard deviation analysis.
- Salary distribution analysis.
- Job-role-based salary comparisons.
- Full-time versus internship compensation analysis.

## Power BI Dashboard
The dashboard includes:
- Total Salary KPI
- Average Salary KPI
- Maximum Salary KPI
- Rating KPI
- Interactive filters and slicers.
- Job-role comparison tables.
- Salary gauge visualization.

## Key Business Insights
- Data Science and DevOps roles show higher salary benchmarks.
- Full-time employees earn substantially more than interns.
- Salary distributions show positive skewness.
- Compensation varies across geographical locations.
- Higher salary brackets show a mild positive relationship with employee ratings.

## Conclusion
This project demonstrates an end-to-end Business Analytics workflow using Excel and Power BI, converting raw workforce data into meaningful insights that can support compensation benchmarking and business decision-making.
